# Редизайн bangertstudio.kz: «Премиальная студия» + продающий копирайт

Дата: 2026-09-06

## Задача

Сайт выглядит как дефолтный тёмный Tailwind-шаблон, а тексты описывают процесс
разработки вместо выгоды клиента. Нужен заметный редизайн всего сайта и
переписанный копирайт, опирающийся только на проверяемые факты.

## Диагноз текущего состояния

1. **Дизайн-система не используется.** `app/globals.css` описывает полный набор
   токенов (`--primary`, `--accent`, `--muted`), но файл заканчивается
   `background-color: #000 !important`, а компоненты рисуют всё через
   `text-white/60` и `border-white/10`. Токены мертвы.
2. **Типографической иерархии нет.** `globals.css` задаёт `h1 { font-size:
   var(--text-2xl) }`, компоненты перебивают это (`Hero.tsx:26` — `md:text-6xl`).
   Каждый заголовок настраивается вручную. `line-height: 1.5` на всех уровнях
   даёт рыхлый крупный кегль.
3. **Все секции одинаковые.** Шесть блоков `py-24 px-6` с центрированным
   заголовком `text-4xl mb-16` подряд.
4. **Hero без доказательств.** Заголовок, подзаголовок, две кнопки — и ни одного
   факта выше линии сгиба.
5. **Кириллица рендерится запасным шрифтом.** `app/layout.tsx:6` грузит Geist с
   `subsets: ['latin']`, хотя шрифт поддерживает `cyrillic` (проверено в
   `node_modules/next/dist/compiled/@next/font/dist/google/font-data.json`).
   Весь русский текст сайта показывается системным Arial/Helvetica.
6. **Тексты про процесс.** «Разработка iOS приложений», «Agile-спринты с
   непрерывной интеграцией» — что делает исполнитель, а не что получает клиент.

## Решения

Направление: **«Премиальная студия»** — тёплая угольная база, крупная
типографика с засечным дисплейным шрифтом, мягкие подсветки, много воздуха.
Голос: «мы» (студия).

### Палитра

Уход от чистого `#000` к тёплому углю — основной приём направления. Чистый
чёрный читается дёшево и контрастно, тёплый уголь — дорого.

| Токен | Значение | Назначение |
|---|---|---|
| `--bg` | `#0A0908` | тёплый почти-чёрный, фон страницы |
| `--surface` | `#121010` | секции-подложки |
| `--surface-raised` | `#1A1716` | акцентные секции, карточки |
| `--hairline` | `rgba(245,242,237,0.08)` | границы по умолчанию |
| `--hairline-strong` | `rgba(245,242,237,0.16)` | границы в hover |
| `--text` | `#F5F2ED` | основной текст, тёплый белый |
| `--text-muted` | `#A39C93` | вторичный текст |
| `--text-faint` | `#6E665D` | подписи, мелочь |
| `--accent` | `#D9A566` | приглушённая латунь |
| `--accent-soft` | `rgba(217,165,102,0.12)` | подсветки, фон бейджей |

**Правило акцента:** не больше трёх появлений на экран — надзаголовок, ключевая
цифра, hover-состояние. В кнопки акцент не идёт: главный CTA остаётся кремовым
(`--text`) на тёмном. Золотые кнопки удешевляют премиальный вид.

Токены объявляются в `:root` и пробрасываются в Tailwind v4 через блок
`@theme inline`. Строка `background-color: #000 !important` удаляется — она и
есть причина, по которой систему токенов невозможно использовать.

### Типографика

- **Дисплей — Playfair Display**, только `h1`/`h2`. Кириллица поддерживается
  (проверено). Засечный высококонтрастный шрифт на тёплом угле — самый быстрый
  уход от шаблонного вида.
- **Текст и UI — Geist Sans**, `subsets: ['latin','cyrillic']`.
- **Метрики, версии, числа — Geist Mono.**
- Шкала на `clamp()` объявляется в `globals.css`, компоненты перестают задавать
  размеры руками:

```
--text-display  clamp(2.75rem, 6vw, 4.5rem)   line-height 1.05
--text-h1       clamp(2.25rem, 4.5vw, 3.25rem) line-height 1.1
--text-h2       clamp(1.875rem, 3.5vw, 2.5rem) line-height 1.15
--text-h3       1.25rem                        line-height 1.35
--text-body-lg  1.125rem                       line-height 1.6
--text-body     1rem                           line-height 1.6
--text-small    0.875rem                       line-height 1.5
```

Правило `h1..h4 { line-height: 1.5 }` из `@layer base` удаляется.

### Ритм секций

Монотонность шести одинаковых `py-24` ломается чередованием подложек и раскладок:

| Секция | Приём |
|---|---|
| Hero | Полный экран, тёплая радиальная подсветка, доказательства под CTA |
| Полоса доказательств (новая) | Тонкая hairline-лента: «10 проектов», «6 в App Store», «12 open-source пакетов», «10+ лет опыта». Числа проектов и пакетов считаются из данных, а не хардкодятся. |
| Кейсы | Широкая сетка на `--surface`, крупные превью |
| Услуги | Асимметрия: заголовок слева `sticky`, список справа |
| Калькулятор | Акцентная секция на `--surface-raised` с подсветкой |
| DevSolutions | Существующая структура, подтянутая под систему |
| Контакты | Крупный финальный блок |

**Порядок меняется:** услуги переезжают выше калькулятора. Сейчас клиенту
предлагают посчитать стоимость раньше, чем он узнал, что студия делает.

### Копирайт

Формула каждого блока: заголовок = выгода клиента, подзаголовок = как именно,
рядом = проверяемый факт.

Примеры переписывания:

| Сейчас | Станет |
|---|---|
| «Помогаем стартапам и бизнесу запускать Мобильные&Веб приложения» / «От идеи до релиза — без лишней сложности» | «Приложение, которое дойдёт до релиза» / «Мобильная и веб-разработка полного цикла. Срок и бюджет вы знаете до старта — не после.» |
| «Разработка iOS приложений» / «Высокая скорость работы и соответствие требованиям Apple» | «Приложение в App Store» / «Берём на себя сборку, требования Apple и публикацию» |
| «Поддержка и обслуживание» / «Постоянные обновления, исправления ошибок» | «Приложение не останется без присмотра» / «Обновления под новые версии iOS и Android, чтобы оно не отвалилось через полгода» |
| «Гибкий процесс разработки» / «Agile-спринты с непрерывной интеграцией» | «Видно, за что вы платите» / «Каждую неделю — работающая сборка у вас на телефоне, а не отчёт о процессе» |

Остальные смысловые строки переписываются по той же формуле, синхронно в
`app/locales/ru.json` и `app/locales/en.json`.

**Разрешённые факты (только проверяемые):**

- 10 проектов в `app/data/cases.json`, из них 6 с живыми ссылками на App Store
- 12 open-source пакетов на pub.dev, живые метрики загрузок и лайков через
  существующий `/api/packages`
- опыт 10+ лет (подтверждён владельцем)
- срок и бюджет известны до старта — с ведением в калькулятор

**Запрещено:** выдуманные числа проектов, клиентов, лет, процентов роста,
отзывы, названия компаний-клиентов, конкретные обещания сроков в неделях.

### Внутренние страницы

- `/cases` — превью 96×96 (`pages/cases/index.tsx:66`) заменяются крупной
  сеткой; на проектах со ссылкой на `apps.apple.com` появляется бейдж «В App Store».
- `/packages` — приводится к системе, метрики моноширинным.
- `/calculator` — токены и типографика; логика расчёта не трогается.

## Границы

Не трогаются: API-роуты (`app/api/*`), zustand-сторы, логика калькулятора,
интеграция с pub.dev, Яндекс.Метрика, структура данных `cases.json` и
`calculator.json`.

## Проверка

- `npm run build` проходит
- `npm run lint` без новых ошибок
- обе локали (`ru`, `en`) рендерятся
- сверка ключей: каждый ключ присутствует и в `ru.json`, и в `en.json`
- визуальная проверка главной и трёх внутренних страниц
